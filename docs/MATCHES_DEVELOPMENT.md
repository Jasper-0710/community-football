## 接口与数据

`adminAuth` 新增 `matches.js`，通过 `index.js` 路由。公开操作为 `matches.listPublic` / `matches.getPublic`；管理操作为 `matches.listAdmin` / `matches.create` / `matches.update`，需要既有管理员会话。公开响应不包含管理版本、创建指纹、领队联系方式或报名材料。

列表按比赛 ID 稳定分页，每页最多 20 条；前台读取全部分页后按开赛时间排序。公开查询要求赛事开启展示，支持已排赛、延期、进行中及完赛状态。比赛阶段为小组、八强、半决赛、决赛；赛程编辑接口仅接受已排赛或延期，比分、状态及比赛事件通过赛果接口写入。

服务端事务读取相关赛事、球队、报名和来源比赛。关联查询与写入通过赛事的 `scheduleMutationVersion` 串行化；引用球队同时递增球队 `version`，遵守 `TEAMS_DEVELOPMENT.md` 的关联保护契约。当前赛果写入同样保留此契约。
