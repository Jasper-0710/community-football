## 入口与行为

- 客户端“赛事 → 晋级对阵”和“数据 → 晋级对阵”共用同一张真实对阵图，先选择公开赛事。
- 四分之一决赛、半决赛、决赛依照实际 `homeFrom` / `awayFrom` 连到对应主客队；顺序从真实下游来源追溯，不按场次号、数组顺序或日期推断配对。没有八强的赛事从半决赛开始；未排赛显示空态，不补造比赛或晋级线。
- 卡片显示实际场次签位、主客队、小组名次/前轮胜者来源、状态、比分、点球、北京时间及场地；点击进入该 ID 的实际比赛详情。未设置 `slot` 的比赛明确显示“第N轮 · 签位未编号”，不把轮次当作场次签位。
- 只有完赛且主客队明确时才标记胜者。点球单独显示，进行中领先不会提前晋级。已确认来源显示绿色连线；决赛与服务端 `championTeamId` 一致时展示冠军，否则保留“冠军待定”。
- 本页沿用“刷新榜单”重新读取同一赛事快照，赛果更正、撤销、重发与小组名次变化后，球队、分数、连线与冠军一起更新。并非实时推送，不承诺后台保存后即时刷新所有已打开页面。
- 手机只在图内横向滑动，提供轮次的横向定位按钮；390/320px没有整页横向溢出。深色外观沿用平台主题。H5赛事选择使用已有视觉容器中的浏览器下拉框，微信保留原生picker。
