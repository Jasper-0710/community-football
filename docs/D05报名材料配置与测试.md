## D05 测试顺序

1. 后台新建独立测试赛事，配置报名项目、人数范围、球队名额和开始/截止时间，开启展示及报名。测试材料使用不含真实身份信息的 PDF/图片/Word/Excel，不修改正式赛事安排。
2. 小程序进入赛事详情 → 为我的球队报名。检查带入的球队名、所属地区和联系方式，填写报名项目、领队姓名，选择材料。先检查格式/大小提示，再上传有效文件。
3. 提交后应显示“待审核”，在“我的报名”可以重新打开；后台“报名审核”应出现同一记录，可以授权下载并打开材料。
4. 后台填写原因驳回，领队能看到原因并修改重提；后台核对参赛人数、勾选材料确认后通过，记录进入“已通过（参赛名单）”。
5. 领队修改已通过报名，应重新进入待审核；截止前撤销应释放名额。到达截止时间后，修改和撤销锁定，但既有记录仍可查看。
6. 分别验证 iPhone 微信原生选文件与打开文档、上传中断重试、第二微信账号不能读取/修改他人报名及材料、最后一个名额并发提交。每项分别记录，不用模拟浏览器测试替代真机和真实云端证据。

## 报名材料维护

后台“报名审核”页面底部展开“报名材料维护”：

1. 点击“检查本批临时材料”，查看可清理、保留和稍后处理的数量。检查默认不删文件，范围覆盖全部赛事。
2. 核对结果后点击“清理本批临时材料”。每次最多检查5条上传记录、删除20个文件；未提交且过期/已移除的文件、已完成上传的残留分片及未采用的合并文件可回收。
3. 有下一批时继续检查；本批仍有剩余或失败文件时，重新检查本批再重试。正在上传的预留对象保留10分钟保护期，清理结果尚未确认的任务保留5分钟重试保护期。
4. 已绑定报名的最终文件一直保留，即使后来被替换或撤销报名也不删历史材料。维护接口不会处理个人头像、球队队徽或其他环境的文件。

当前为管理员主动触发的批量维护，**没有自动定时任务**；24小时有效期不代表存储文件会自动物理删除。新上传先登记对象再传输，便于中断后回收；旧版本未登记且无法确认归属的存储对象不会按文件名前缀盲删。
