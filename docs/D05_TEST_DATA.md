## 2. 先测01：撤销报名和名额释放

开始前先保留待审核状态，不要在后台将这条报名审核通过或驳回。

1. 小程序进入 **我的 → 查看我的报名**，找到“【验收01】截止前撤销释放名额”，进入 **查看报名与材料**。
2. 后台进入 **球队报名审核**，选择同名赛事，点击 **刷新报名**。初始应为待审核1、已占用1。
3. 小程序点击 **撤销报名**，在确认弹窗选择取消。重新进入后仍为待审核，后台刷新后仍占用1。
4. 再次点击 **撤销报名**，这次确认撤销。页面应显示已撤销和名额已释放；后台刷新后显示已撤销，待审核0、已占用0。
5. 小程序点击 **重新报名**，核对原资料和材料后提交。可以继续使用原材料；应回到待审核，后台待审核1、已占用1。

第4步完成而第5步尚未执行时，名额为空；如需验证“另一支球队能占用释放名额”，让第二真实账号在此时报名。第二队占位后，原队再次报名应提示名额已满。此分支需要两个人配合，不能用同一账号重新报名替代第二队验证。

反馈可按下列格式：`01-取消确认：通过/问题；01-撤销与计数：通过/问题；01-重新报名：通过/问题`。只确认实际完成的分支。

需要两个真实微信账号，各自已登录并管理一支有效球队。当前库中虽然有两支球队，仍需要各自所有者真实操作；不会冒用另一位用户报名。

2. 各自填写领队信息，选择“验收足球”，上传本文配套的模拟材料。第一位不要提前提交，等两人都准备好。
3. 两人尽量同时点击提交并确认。预期只产生1条有效占位报名，另一人收到名额已满反馈。
4. 后台刷新此赛事，核对总占用为1，没有超额，也没有重复报名记录。
5. 两人各自查看 **我的报名**，应只能看到本人记录。他人详情、附件、撤销接口的拒绝，需要再结合两账号接口联调验证；仅列表不可见不能替代全部权限结论。
