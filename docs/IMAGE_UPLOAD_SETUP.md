## 本次个人头像功能

- 未设置头像时显示默认人物图案；登录后从云端读取本微信账号已保存的头像。
- 在“我的 → 个人资料 → 个人头像”主动选择微信头像或相册图片，预览后点击“保存资料”。首次保存需要填写昵称，不会静默替用户设置微信头像。
- 取消选择不修改资料；“放弃修改”恢复当前已保存的头像与昵称；退出登录清除页面状态，云端资料保留。
- 图片宽高与体积分别检查；大图按原比例压缩，最长边目标512像素，文件目标不超过256KiB。PNG/JPEG在云端再次真实解码和校验，文件路径由可信身份生成。
- 登录时原头像签名失败或文件不可用，仍可登录和保存昵称，页面显示默认图案与重试入口，保留原文件引用以便恢复。
- 图片加载失败时自动刷新一次云端链接，也可点击“重新加载”；刷新不清空未保存的昵称和头像草稿，退出或保存后的过期请求不能覆盖新状态。
- 新头像上传或签名失败不替换旧头像。替换后旧文件暂保留，引用核对与清理另行落实。

## 开通操作

1. 微信开发者工具 → 云开发 → 确认环境 `cloud1-d6gzg20x709d7f6c1` → 云存储 → 权限设置。选择“仅管理员可读写”；如果只有自定义规则编辑器，保存：

   ```json
   {"read": false, "write": false}
   ```

   这是云存储规则，与数据库 `users` 等集合的规则不同。客户端通过云函数上传和取得短期链接，不需要开放整个存储桶。
2. 云开发 → 云函数 → `userProfile` → 配置，将“执行超时时间”设为20秒。打开环境变量，新增或修改 `USER_PROFILE_AVATAR_ENABLED`，值为小写字符串 `true`；保留其他环境变量。它不是本机的 `VITE_` 变量。
3. 本次 `userProfile` 代码更新已确认部署成功，无需重复部署确认。保存配置后重新读取云端状态；自动化接口不能设置存储规则、环境变量和执行超时，所以需要控制台操作。
4. 开启后先复测客户端直传被拒绝，再测试云函数实际上传和签名下载。若客户端仍能直传，先将开关改回 `false`，排查规则与环境，不能标记完成。
