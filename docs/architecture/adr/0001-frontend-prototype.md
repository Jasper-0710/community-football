# ADR 0001：同一份 uni-app 源码交付 H5 原型与微信编译产物

日期：2026-10-25
状态：采用，等待微信开发者工具和真机验证

## 决策

使用 uni-app、Vue 3、TypeScript、SCSS。依赖基于 dcloudio/uni-preset-vue 的 vite-ts 官方模板版本系列，裁剪至 H5 和微信平台，并保存 package-lock.json。

根页面内使用五区导航，详情采用真实页面路由。先实现可点击 Mock 原型，数据源在 repository 中独立，暂不加入状态管理大库、路由大库或后端基础设施。

## 备选方案

- 纯 Vue 网页再改写小程序：网页搭建自由，但需要后续重做组件/导航/平台适配。
- 微信原生：目标直接，但不利于本轮浏览器快速预览。
- Taro + React：可行，但当前没有 React 代码和团队约束，切换没有明确收益。

## 取舍

- 共享类型、数据与大部分布局，仍需分别验证两个平台。
- 采用 view/text/image 等跨端组件；原生按钮默认样式通过共享基础类控制。
- 不把架构扩大为复杂仓储/用例/状态分层。纯函数与一个可替换数据入口足以支持本期目标。
- 不提前实现 8 套主题、管理后台或真实评分功能。
