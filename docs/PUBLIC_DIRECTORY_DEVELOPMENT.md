## 已实现

- 首页头图置前，赛事采用最多三项的简洁预览；球队数、比赛数、赛事数、比赛日和最多六支球队读取公开业务服务，不再使用固定的八支演示球队或演示日期。比赛日优先进行中比赛所在日期，再选北京时间今天、下一个比赛日、最近比赛日；有超过六场时显示总数与完整赛程入口。
- “去看比赛”“全部赛程”进入公开赛程，“认识球队”进入公开球队查找；预览可进入实际比赛与球队档案。公告、新闻、积分榜保留既有公开数据链路。首页、新闻、榜单等根页面不再由示例赛事对象的加载结果控制；示例赛程与示例球队仍单独标识。
- 球队档案保留介绍、队徽、名单和收藏，新增按赛事筛选的已赛、胜平负、进失球及净胜球，以及完整分页赛程和赛果。球员档案新增进球、助攻、红黄牌和对应比赛的分钟事件，支持按赛事筛选及返回所属球队。
- 加载、真实空态、失败重试、过滤范围已隐藏后的返回全部赛事、分页变化冲突及过期响应保护齐备。新接口复用 D13 主服务、云端备用和本机快照机制；权威不存在/权限失败不会回退旧内容。

## 统计与公开范围

1. 只有 `displayEnabled=true` 的赛事、该赛事报名通过且未解散的球队参与公开投影。不能因球队在赛事甲已公开，就泄漏其在隐藏赛事乙或待审核赛事丙的记录。资格失效的前轮不继续生成旧晋级球队。
2. 球队只统计 `finished` 的有效赛果；进行中比赛显示在赛程，不计累计战绩。胜平负按点球大战前比分计算；点球比分单独显示，不加到进失球，也不把点球平局计作普通胜场。
3. 球员以当前公开球队名单的球员 ID、球队 ID 与赛果事件匹配。统计已完赛进球、助攻及红黄牌；乌龙球和点球大战不计个人进球。换上/换下仅展示已记录分钟，不推算出场次数、首发或上场时间。名单更名、号码变更不丢失同一 ID 的历史事件；移出当前公开名单后不再提供该档案。
4. 每次读取从当前事实重算，不持久化重复统计表。赛果更正、撤销和重发后，累计数据和晋级来源重新计算。继续使用现有榜单引擎解析小组名次和前轮胜者；本轮没有新增对阵树或单场历史恢复功能。
5. 公开响应只白名单输出姓名、号码、位置、公开球队资料及赛事事实，不输出领队身份、联系方式、报名附件或后台版本。档案每页 20 场；游标绑定查询范围及当前投影，相关记录变化后要求刷新。底层保持现有每集合 2000 条扫描上限，超过上限报错，不静默截成完整统计。

## 接口及部署

| 新公开只读操作 | 参数 | 响应 |
| --- | --- | --- |
| `directory.homePublic` | 无业务参数 | `home`：北京时间日期、统计数量、比赛日和球队预览 |
| `directory.teamProfilePublic` | `id`、可选 `competitionId` / `cursor` | `team` 与 `record`：公开基本资料、统计和比赛页 |
