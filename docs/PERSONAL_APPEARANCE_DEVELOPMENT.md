# D10 客户端个人外观设置

更新：2026-11-18。个人外观已完成代码、自动测试、隔离浏览器回归及微信模拟器当前账号的本机保存/重入验证。此功能只保存本机偏好，不新增云集合、云函数或平台管理写入；微信真机与客户整项签收另行记录。

## 使用方式

入口为客户端 **我的 → 外观设置 → 设置个人外观**，页面路径 `pages/profile/appearance`。游客也可使用。

- 配色：八套现有主题、自选六位十六进制主色，或“跟随平台配色”。
- 明暗：浅色、深色，或“跟随平台明暗”。
- 圆角：直角、柔和、圆润，或“跟随平台圆角”。
- 三项分别选择；个人选择优先生效，跟随项使用平台最新值。平台名称、副标题和六导航的名称、图标、顺序及目标始终由后台统一管理。
- 未保存只影响“效果预览”。“保存外观设置”成功后应用到所有页面及图标；“放弃修改”恢复已保存内容。“全部跟随平台”先修改预览，再保存生效。
- 返回个人中心、进入详情和刷新后保留本机选择。独立打开或刷新外观页后，页面内“返回个人中心”直接进入“我的”。

## 身份与本机保存

记录采用版本1结构 `{version, owner, form}`，存储键按环境ID、公开接口地址、当前身份的JSON元组隔离。身份只来自现有云登录确认的用户ID；缓存中的用户ID不能建立登录态，也不参与业务授权。

游客单独保存；登录后读取当前账号在本机的偏好，不复制游客偏好。退出立即切回游客，另一账号读取自己的记录。同账号修改昵称或头像不会重置外观草稿。页面切换后共享身份监听仍有效；身份改变时清空旧草稿，旧登录周期的保存请求拒绝执行。

本轮不包含个人外观的跨设备同步。清除本机缓存会移除这些选择。收藏云同步同日已独立开发并本地回归，客户部署和真实闭环待做，见[收藏说明](FAVORITES_DEVELOPMENT.md)。

读取时校验记录版本、归属及完整外观字段；损坏、归属不匹配或读取异常回退到跟随平台并显示提示。保存时先校验并写入，再应用到页面；存储空间不足等写入失败不会改变当前外观，可保留草稿重试。未填完整的颜色不会进入CSS，预览使用安全回退色。
