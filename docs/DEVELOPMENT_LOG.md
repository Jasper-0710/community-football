### 本次实现

- “我的”页面显式微信登录、自动恢复已登录意愿、退出本机、加载、取消、失败重试；H5 保持游客并提示在微信登录。
- 微信云函数 `userProfile` 根据可信微信上下文建档；客户端不提交身份，不可授予自己领队或管理员角色。
- 昵称编辑和云端保存可用；头像选择、压缩、图片解码和保存代码已准备，但入口及云端头像写入默认关闭。服务端开关 `USER_PROFILE_AVATAR_ENABLED` 只在后续权限配置和验证完成后启用，头像不作为已验收能力。
- 通过事务及确定的用户 ID 避免重复档案；读取不会重置已有资料。昵称更新不覆盖角色等其他字段。
- 本机只缓存登录意愿，重新进入时从云端读取资料；不以缓存资料冒充已登录。超时和云端错误显示失败，保存结果不明时提示重新读取。
- 收藏暂时仍是设备本地数据；建队、报名、后台账号密码登录及其他需求按后续任务执行。

### 数据与接口

集合 `users` 的客户端安全规则为 `{"read":false,"write":false}`。`_id` 为 `sha256(APPID + ':' + OPENID)`，使用内置唯一标识；`appId`、`openId` 仅在云端保存。其他字段：`nickname`、`avatarFileId`、`role`、`createdAt`、`updatedAt`。首次角色为 `user`，昵称允许为空；编辑昵称时要求 1–30 个 Unicode 码点且不含控制字符。

`getOrCreate` 读取或建立本人档案；`update` 接受昵称。头像开关启用时才接受可选 PNG/JPEG Base64 头像，最大 256 KiB；当前关闭时返回 `AVATAR_UNAVAILABLE`，不会连带保存请求中的昵称。响应包含布尔能力字段 `avatarUploadEnabled`。平台附带的 `userInfo`、`tcbContext` 被忽略，不能覆盖可信 `getWXContext()`。任何其他未知字段均拒绝。接口细节见 [云函数说明](../cloudfunctions/userProfile/README.md)。
