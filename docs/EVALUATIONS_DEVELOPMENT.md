## 已实现范围与入口

- 后台“赛事管理 → 评分与评选”：选择赛事及已完赛比赛，维护评分窗口、查看球员评分汇总、审核评论、发布本场 MVP 与最佳阵容。
- 客户端“赛事 → 真实已完赛比赛详情 → 评分与评论”：查看本场平均分、人数、公开评论和已发布评选。微信登录后可提交；H5提供查看及微信参与提示。
- 赛事级统一评分窗口：开关、评论开关、分数范围、起止时间。后台统一显示北京时间，保存和回填没有8小时偏移；对该赛事所有完赛场次生效。
- 每个可信微信账号对本场每名球员保留最新一份评分和评论。默认1–10分，评论1–300字；重复请求幂等，同一请求标识改内容拒绝，重试旧请求不覆盖新值。
- 评论提交及修改后均待审核；后台可审核公开、隐藏或恢复。审核携带版本，旧页面不能公开用户刚修改的内容。
- **MVP与最佳阵容按场次隔离**。最多一名MVP，阵容球员及顺序不能重复，支持可选位置；清空后发布可撤下。赛果撤销后不公开评选。
- 候选来自本场两支已通过报名的球队；淘汰赛使用赛果已解析的球队ID。当前读取球队现有名单，历史参赛名单冻结不在本次成果内。
- 配置、评分、评论和评选写入均在事务内校验；配置/评选版本冲突、响应中断要求先重读确认。公共接口不返回身份哈希、请求历史、隐藏评论或管理员字段；HTTPS公开读取不携带实例残留微信身份。
- 前后台切换/卸载隔离迟到响应，读取失败清除旧内容；赛事隐藏后移除旧评论/评选。

默认评分/评论关闭。上述为当前可配置基础口径，客户最终评分范围、参与资格和最佳阵容规则及整项签收继续独立跟踪。

## 数据与接口

服务：`cloudfunctions/adminAuth/evaluations.js`；路由：`adminAuth/index.js` 的 `evaluation.*`。四个集合都应配置自定义私有规则 `{"read":false,"write":false}`，不能开放客户端直读写：

| 集合 | 用途 |
| --- | --- |
| evaluationConfigs | 赛事统一窗口、版本及请求去重 |
| playerRatings | 用户对本场球员的最新评分 |
| playerComments | 用户对本场球员的评论、审核状态及版本 |
| playerAwards | 以matchId为文档ID的本场MVP/阵容 |

`evaluation.getPublic`允许公开读取；`rate/comment`仅通过可信微信云调用写入；`getAdmin/configure/moderateComment/publishAwards`需要管理员会话。评分/评论按matchId分页查询，每页100条，超过2000条明确失败而不返回截断汇总；规模及索引适配尚待云端实测。

此功能不新增环境变量。部署须保留adminAuth既有配置和20秒超时。
