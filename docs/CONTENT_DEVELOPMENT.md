## 数据与权限

新增集合`newsArticles`及`newsImages`，由`adminAuth`云函数读写，客户端直接读取或写入均须关闭。客户云端本轮真实写入、读取、权限隔离和图片清理均已完成；微信iPhone/Android真机及正式图片域名仍需单列验收。

新闻ID为`n_`加32位创建请求ID。记录包含标题、五类分类、摘要、作者、HTTPS封面、图文段落、发布状态、置顶、可选赛事ID、版本、创建/更新时间、首次发布时间及删除时间。创建请求使用内容指纹防重复；更新和删除以`expectedVersion`检查并发。删除保留内部记录，公共及管理查询均不再展示。编辑不会修改首次发布时间。

公开列表、直达、首页和搜索只返回已发布且未删除的内容。关联赛事隐藏时，其文章及比赛同步退出公开范围。公开球队/球员限于至少一场公开赛事中报名已审核通过的有效球队，不公开待审或已解散球队名单。后台按真实管理员会话鉴权，客户端传入的角色和微信元数据不授予权限。

公开返回值逐字段投影，排除手机号、领队身份、材料、创建指纹、托管图片ID及管理版本。正文使用文字和图片块渲染，不插入原始HTML。外部图片只接收无凭据的HTTPS地址；托管图片在文章中保存图片ID，签名URL不持久化。后台图片安全策略允许本地blob预览与HTTPS图片，脚本策略保留。

## 图片存储与一致性

上传仅限有效管理员，默认关闭，通过`adminAuth`环境变量`NEWS_IMAGE_UPLOADS_ENABLED=true`开启。单张不超过2MiB，边长不超过4096像素，总像素不超过800万；选图时先检查尺寸，服务端解码PNG/JPEG，校验PNG结构/CRC/有界解压、JPEG结束和解码结果，不仅检查扩展名。每片64KiB，文件及分片以SHA-256校验。相同请求重试复用图片ID及已传分片；旧版192KiB未完成会话只有未写对象时才迁移，已有分片或预留对象则新建会话，保留旧对象等待正常清理。已完成旧图片仍可读取和关联。

图片ID为`ni_`加32位请求ID，绑定唯一文章ID。新文章在保存前已有创建ID，因此可先上传。登记集合只保存元数据、私有对象清单及引用状态；存储对象限制为本环境`news-images/staging/`及`news-images/files/`下当前图片的路径。先登记对象与10分钟上传保护期再写入字节，云端上传执行须短于该保护期；不明上传结果仍可跟踪和清理。

文章与图片引用在同一事务绑定/解绑。旧版本、跨文章图片、未完成/过期图片及事务失败不改变原引用。替换或删除文章仅解除引用，旧图保留24小时；未保存候选上传也保留24小时。清理会重新核对文章实际引用，并在同一图片记录上取得清理保护，避免并发保存误删；只删除本环境登记且路径合法的对象，仍被草稿或已发布文章引用的最终图片保留。临时分片及并发完成产生的未采用最终对象在保护期后可清理。没有定时自动清理。

每次授权读取文章生成约5分钟HTTPS访问链接。草稿、隐藏赛事和删除内容不向公开入口签发新链接；此前已经签发的链接在到期前仍可能有效，不保证立即撤销。后台可刷新单图链接，前台图片失败可重新加载文章。文章事务已提交但签名失败时，明确返回`WRITE_COMMITTED`并阻止页面重复保存，要求刷新重读。新闻分页摘要基于持久化记录，签名变化不会使游标失效。

## 搜索与统计口径

搜索词最多40个Unicode字符，进行NFKC、空格和大小写规范化。排序依次为名称完全匹配、名称前缀、名称包含、其他字段包含。同级按球队/球员/比赛/新闻类型、规范化标题及ID稳定排序。其他字段包含球队地区/介绍、所属球队/号码/位置、比赛场地/赛事/状态，以及新闻摘要/文字正文。

基础热门词来自公开球队名与五类分类，**未实现真实搜索频次和热度统计**。历史仅存于当前设备，不建立服务端用户搜索档案。

新闻置顶优先，其后按发布时间倒序，同刻按ID稳定排序。新闻和搜索每页20条，游标绑定查询范围及结果摘要；相关内容变化后旧游标返回冲突，要求刷新，避免静默重复或漏项。

数据库适配器以默认`_id`索引逐页读取，每页100条，每集合最多2000条。超过上限返回不可用，不把截断结果当完整榜单。此为基础规模方案，尚未实现倒排索引、全文搜索或大规模性能验收。公开可见范围使用当前审核状态和当前名单，不等于历史赛果中的球员快照。

概览在管球队排除已解散档案；比赛数包含所有在管赛事的比赛；进球仅累计完赛比分，不计进行中及点球大战；新闻数排除已删除记录，已发布数包含关联隐藏赛事的已发布管理内容。返回的是本次读取的数据，变更后刷新更新。

## 接口

| 接口 | 访问范围 |
| --- | --- |
| `news.listPublic` / `news.getPublic` | 公开新闻列表/图文详情 |
| `news.listAdmin` / `news.getAdmin` | 管理列表/详情，含草稿 |
| `news.create` / `news.update` / `news.delete` | 管理写入、幂等创建和版本检查 |
| `news.images.config` / `start` / `chunk` / `finish` / `get` | 管理上传配置、分片会话、完成解码及授权链接 |
| `news.images.cleanup` | 管理清理预览/执行，支持分页及失败后重新检查 |
| `search.public` / `search.admin` | 各自权限范围内四类搜索 |
| `search.suggestions` | 公开球队/分类推荐词 |
| `directory.teamPublic` / `directory.playerPublic` | 基础公开档案 |
| `content.overview` | 管理运营概览 |

复用现有`/admin-suth`网关。公开操作显式加入HTTP白名单，管理操作仍要求Bearer会话。文字段落最多2000字符、正文1–30段，整份规范化表单最多12000字节。普通请求保留16KiB限制，仅`news.images.chunk`保留270000字节的应用层上限；实际客户端每片只传64KiB二进制，Base64与JSON合计不到9万字节，避免先触发云网关413。仍须管理员Bearer会话。
