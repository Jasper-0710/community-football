## 本机与其他电脑统一配置

```bash
npm ci
npm run cloud:setup
npm run cloud:check
```

`cloud:setup` 生成本机 `.env.local` 和 `.env.admin.local`；这些文件不进入 Git。小程序及后台每次启动/构建都会校验环境 ID 和 AppID，发现其他环境的 CloudBase 地址即报错，不会静默回退到旧环境。旧环境联调脚本已在本机停用，历史原稿存于 `.tools/legacy-environment/`，不得在新环境执行包含旧数据 ID 的脚本。
