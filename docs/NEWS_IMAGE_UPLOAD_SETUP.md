## 非空验收

| 操作 | 预期 |
| --- | --- |
| 管理员新闻页新建内容，选择封面PNG和正文JPG | 有本地预览/进度；单张≤2MiB、边长≤4096、总像素≤800万；未完成时不可保存，正文可排序且不串图 |
| 断网或失败后重试 | 相同请求跳过已成功分片；可取消候选，原图保留；无效类型或损坏图不能完成上传 |
| 保存草稿再发布，前台刷新首页/列表/详情 | 草稿不公开；发布后可下载解码图片，封面与正文一致，文章记录只存图片ID，不保存临时URL |
| 替换失败后取消、替换成功后保存 | 取消保留原图；成功后新图关联，旧图解除引用并保留24小时 |
| 图片URL失效、重新打开文章或手动刷新 | 获得新短期URL；前台失败显示“重新加载图片”，不会无限自动重试 |
| 未登录调用上传/链接/清理，客户端直接读写两集合或存储 | 全部拒绝；跨文章使用图片ID拒绝，旧版本保存不改变引用 |
| 取消发布、隐藏关联赛事、删除文章 | 公开入口不签发新链接；之前签发URL最多仍可使用约5分钟。删除仅解除引用，保留期后才能清理 |
| 图片维护先检查再清理，必要时检查下一批 | 每批≤20条记录，预览不删；过期候选和临时分片清除，草稿/已发布使用的最终图保留，失败可重新检查重试 |

清理真实数据前用明确标记的验收文章和图片，核对返回对象数量及对应引用。没有自动定时清理；不会删除其他环境、报名、头像或不符合登记路径的对象。存储对象数量不同于图片数量，因为一张图可能有多段临时分片。

保存返回`WRITE_COMMITTED`表示文章已写入但链接暂不可用，应刷新列表重新读取，避免按旧版本重复提交。接口超时且结果未知时同样先读取实际状态。
