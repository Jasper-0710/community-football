## 前置条件完成后的报名测试顺序

以下预期按当前代码实现；待审核占位、驳回释放、修改重审和附件限制等细则仍需业务确认。

| 顺序 | 操作 | 预期结果 | 核对结果 |
| --- | --- | --- | --- |
| R01 提交 | 小程序 → 赛事详情 → 为我的球队报名 → 核对球队名/地区，选择测试项目，填写领队姓名/联系方式 → 选择报名材料 → 等待上传完成 → 提交报名 | 显示待审核；我的报名和后台报名审核出现同一条记录；占用名额增加1 | 待填 |
| R02 材料打开 | 我的报名 → 详情 → 查看材料；后台 → 报名审核 → 选择赛事和报名 → 下载 | 本人和管理员能打开正确文件；格式/大小与上传一致；其他账号不可读取 | 待填 |
| R03 驳回与重提 | 后台填写“测试：请补充材料”→ 驳回报名；小程序重新读取 → 修改资料/材料 → 重新报名 | 小程序显示原因；驳回释放名额；重新提交回到待审核并重新占位 | 待填 |
| R04 审核通过 | 后台下载材料，填写核对后的参赛人数，勾选“已核对报名材料与参赛要求” → 审核通过；筛选“已通过（参赛名单）” | 两端显示已通过，参赛名单包含该队；超出赛事人数要求时拒绝通过 | 待填 |
| R05 修改重审 | 报名截止前，小程序 → 我的报名 → 详情 → 修改报名资料 → 保存修改并重新审核 | 状态回到待审核，不额外占用第二个名额；当前球队档案不因报名表修改而被覆盖 | 待填 |
| R06 撤销/重试 | 截止前在报名详情撤销并确认，刷新两端；开发侧验证重复提交/撤销请求 | 显示已撤销，释放1个名额，重复请求不重复计数；历史报名保留，仍会阻止解散球队 | 待填 |
| R07 截止锁定 | 在报名开放时重新提交一条待审核报名，再给测试赛事设一个即将到来的截止时间；等待截止后重新进入详情，尝试修改/撤销，并用未报名球队尝试新报名 | 领队写入被拒绝；后台仍可审核既有待审核记录；页面时间使用北京时间 | 待填 |
| R08 边界与并发 | 开发侧准备不同账号/球队，验证最后名额竞争、重复请求、版本冲突、越权读取、上传失败重试、10MB边界和非法文件 | 不超售、不重复报名、不越权、不接受非法文件；失败不会显示成功，恢复后状态一致 | 待填 |

当前附件限制为1–5份、每份≤10MB；支持PDF、JPG/PNG、DOCX/XLSX，不支持旧版DOC/XLS。这是当前建议实现，不能当作已经完成客户确认。
