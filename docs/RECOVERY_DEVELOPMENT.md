## 使用入口

管理员登录后，在左侧菜单“平台设置”下方进入“备份与恢复”。云端尚未启用时，页面显示部署提示并禁用生成和恢复按钮。

1. 点击“生成并下载JSON备份”，服务端冻结业务写入、扫描业务数据，将最终文件另存到私有云存储。浏览器分片下载JSON并校验SHA-256。
2. 选择本环境导出的原始JSON，先核对环境、格式、云端登记摘要、关联记录及归档文件，再显示新增、替换、删除数量。预览有效期10分钟。
3. 输入页面给出的完整确认文字，再执行恢复。恢复会替换备份覆盖的业务范围，包含删除备份中不存在的记录；执行前自动创建“恢复前回退备份”。
4. 执行结果不明或刷新页面后，先点击“检查恢复结果”。执行中保持锁定；确认未执行时会撤销原预览，必须重新校验。服务端记录完成回执，重复提交已完成任务只返回结果，不重复恢复。
5. 需要撤销恢复时，从历史下载对应“恢复前回退备份”的JSON，重新校验差异并确认恢复。

## 恢复并发与失败处理

三个业务云函数使用同一份恢复保护文件。写请求持有120秒调用租约，包含事务外的文件上传/清理；已有调用未完成时不获取排他锁。备份、预览及恢复期间，新业务读取/写入返回维护状态；公开读取可以使用下述备用或本机快照。

恢复预览绑定管理员会话摘要和完整业务摘要。执行时重新读取业务数据，预览之后任何业务变化都会拒绝覆盖；先归档当前状态，核验备份文件，再在一个事务中核对变更记录、写入差异及完成回执。数据库失败不留下部分业务写入。归档或文件补回可能已发生，但没有完成回执不算业务恢复成功。

原文件明确不存在时可从归档补回；原文件内容不符或网络错误导致无法核实时停止，不能据此覆盖文件。调用租约和排他锁超时后自动失效；部署的三个业务函数执行超时须小于120秒，现有20/60秒配置应保留。实际云运行时长、事务限额及大文件耗时仍需真实环境验证。

## 客户端故障读取

公开读取顺序为：主业务服务 → 已配置的独立 `publicRead` 云函数/HTTPS入口 → 本机已确认公开快照。主服务的不存在、权限拒绝和格式错误不会触发旧内容回退；身份、报名材料和带本人评分的评价响应不进入公共快照。

| 数据来源 | 策略 |
| --- | --- |
| 主服务 | 仅保存经过领域解析器投影的成功公开响应，不持久化额外私有字段 |
| 云端备用 | 主服务成功读取时发布到私有 `recovery-public/<查询摘要>.json`；精确匹配参数和分页游标，2分钟有效、单对象不超过512KiB。独立函数读取对象，不依赖主业务数据库 |
| 本机快照 | 按环境和主接口隔离，精确匹配筛选/游标，最多40份、约100万字符、30分钟有效；备用内容不会刷新本机主服务确认时间 |
| 提示与写入 | 显示备用/本机来源和本机快照原时间，提示内容延迟、图片链接可能过期；故障或展示快照时阻止云端保存，不排队离线提交 |
| 重新连接 | 网络恢复、回到前台或点击“重新连接”时刷新已挂载页面；当前备用读取未恢复则保持只读，已关闭页面的旧提示在成功重连后清除 |

备用只覆盖之前实际请求过且未过期的公开查询，不是完整数据库镜像；没有任何有效快照时显示真实失败，不切换成演示赛程。云存储或整个环境也故障时，备用可能不可用。断网时无法即时撤回已缓存的隐藏内容，最长受上述有效期限制；服务器端过期校验不等于已自动删除云存储对象。正式上线前需确认该缓存口径与资源/保留策略。
