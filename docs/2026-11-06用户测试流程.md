**先获取新版：** 已重新构建小程序。微信开发者工具点击“编译”，然后重新“预览”生成二维码，手机退出旧预览后扫描新二维码。解散确认卡片应有“复制队名”和队名匹配提示；没有这两处说明仍是旧版。如果编译后仍显示旧版，清理开发者工具的“编译缓存”再编译，无需清理账号或云数据。

**T04复测：** 我的 → 我的球队 → 添加球员，分别执行：

1. 留空姓名，填写合法且未用号码和位置，点击“保存球员”：姓名下方提示“请填写球员姓名”。
2. 填姓名，号码输入0，点击保存：号码下方提示“球衣号码须为1–99的整数”。
3. 输入本队已有号码：提示该号码已被哪名球员使用，名单不增加。
4. 改为未用号码，完成保存：出现保存成功提示，名单更新。编辑球员保留其原号码应允许保存。
5. 移出球员时先取消、再确认：取消有提示且名单不变，确认成功有提示且名单减少。后台刷新核对。

**T05复测：** 仅对允许解散的测试队执行：

1. 记录当前队名及名单，进入页面底部“球队管理 → 解散球队”，先点“暂不解散”，资料应保留。
2. 再次进入，输入错误名称：显示“队名尚未匹配”，确认按钮不可用。
3. 点击“复制队名”，粘贴到输入框并收起键盘：应显示“队名已核对一致，可以确认解散”，确认按钮可用。手动输入相同队名也应可用；首尾空格会忽略，中间空格与标点必须一致。
4. 若当前队需要保留，到此点击“暂不解散”，仅记录输入确认通过，完整T05继续待测。
5. 若是可丢弃测试队，确认解散 → 后台刷新查看“已解散”档案与原名单 → 小程序创建新队。三个环节全部符合预期后，才将完整T05记为通过。

T05名称核对：用户提供“上海社区足球队11111”，当前云端完整名称为“联调测试·上海社区足球队11111”，少了“联调测试·”前缀。若确认框输入前者，会因不完全匹配而禁用。模拟器已验证该短名称不能确认、完整名称可以确认；新版还支持忽略首尾空格，并补充就近匹配提示、复制入口及输入/失焦/完成事件处理。请在iPhone新预览中复制完整名称复测，当前不自动修改球队名称。

## 开始前的准备

1. 使用iPhone上的微信测试小程序，使用电脑浏览器测试管理后台。小程序的H5网页预览不能代替真实微信登录和真机验收。
2. 当前按原开发环境 `cloud1-d2goo1h1mee3b7a38` 测试。切换到客户新环境后，要重新验证登录、球队归属、文件和报名流程；旧环境的通过记录不能自动算作新环境通过。
3. 管理后台入口是 http://127.0.0.1:5174/ ，仅表示运行后台网页的这台电脑。它不是手机或客户可直接访问的正式网址。
4. 后台打不开时，在终端执行以下命令并保持运行：

```bash
cd /home/ubuntu/Desktop/PROJ/MINIprogram/MINIprogram
CHOKIDAR_USEPOLLING=true npm run dev:admin
```

5. 微信开发者工具打开项目根目录，确认是最新代码，点击“预览”，用已授权微信的iPhone扫码。如需重新构建，在另一个终端执行：

```bash
cd /home/ubuntu/Desktop/PROJ/MINIprogram/MINIprogram
npm run build:mp-weixin
```

6. 使用名称明确标为“测试”的赛事和球队。先完成解散/重建，再做真实报名：任何报名历史，包括已撤销记录，都会阻止该队解散。
7. 检查测试赛事的报名时间。旧记录可能已经到期；要检查报名表时，将测试赛事的开始设为已过去、截止设为未来，并开启展示与报名。只调整测试赛事，不更改正式赛事安排。

## 第二轮：环境准备后再测试完整报名

当前尚无新付费云环境接入完成的记录。以下事项由开发侧先处理，用户不用反复修改原免费环境：

1. 接入客户AppID/云环境，部署对应代码、集合、索引、管理员和接口。
2. 设置并实测云存储私有权限，确认授权上传与下载可用后，开启报名材料功能。
3. 核实函数执行超时及上传实际运行。原环境存在“用户控制台显示60/20秒、工具回读3/3秒”的差异，保留待核实状态。
4. 建立时间有效的测试赛事，设置测试组、2队、每队1–20人等联调参数；准备已登录且拥有球队的测试账号。

准备一份含虚拟参赛名单的PDF，例如4名测试球员，先放到自己的微信聊天记录中，便于小程序从聊天文件选择。当前代码支持PDF、JPG/PNG、DOCX/XLSX，1–5份、每份不超过10MB；这套附件限制以及待审占位、驳回释放和修改重审等细则仍需业务确认。

## 本轮暂不验收的功能

- 个人头像：代码已有但功能关闭；环境准备并启用后单独验证选图、保存和重进显示。
- 球队队徽：上传接口与界面尚待开发，开通付费环境不会自动具备队徽上传。
- 后台直接增改删球队/球员：目前档案页面只读，编辑从小程序领队入口进行。
- 真实赛程、赛果、红黄牌、榜单、新闻等后续功能：现有示例不算业务验收。
- Android、同账号跨设备：设备条件尚未具备，继续留待验证。
- 过期/孤立附件自动清理：属于D05剩余开发事项，不是请用户操作即可验证完成的功能。
