## 本地球队与赛程数据包

```bash
npm run demo:data
```

命令使用实际赛事及赛程服务，在本地生成并校验 3 场赛事、8 支虚构球队和 28 场比赛。没有网络请求，也不写入云端。

- `artifacts/demo-events/dataset.json`：完整数据集。
- `artifacts/demo-events/competitions.jsonl`：赛事记录。
- `artifacts/demo-events/teams.jsonl`：虚构球队，无真实联系电话、用户绑定或球员资料。
- `artifacts/demo-events/matches.jsonl`：秋季赛事 19 场、五人制 6 场、冬日杯 3 场，包含延期及待定晋级对阵。

生成器校验赛事日期范围、晋级来源归属及时间顺序、同队同时段重复比赛和记录总数。生成产物位于 Git 忽略目录，可通过命令重建。云端赛事已经由 API 创建，不应将本地赛事文件覆盖导入客户数据库。

生成器仅在本地使用模拟的审核资格来校验排赛，不创建或导出真实报名及审核记录。云端确定参赛球队必须经过本赛事报名审核，不能将本地赛程文件直接导入来跳过这项检查。
