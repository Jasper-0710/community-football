# 社区足球 UI 约定

这是项目规范，不是已安装的外部 skill。后续如需跨项目复用，可通过 skill-creator 整理为 community-football-ui。

## 视觉

- 暖白背景 `#f6f7f4`、深绿正文 `#233a2e`、主色 `#1e6b48`，浅草绿只用于强调。
- 主内容最大宽度 1200px，桌面居中；手机边距 18px（小于 360px 时 13px）。
- 大面积摄影仅用于赛事封面与新闻。比分、队名、榜单必须保留为文本，不烘焙到图片中。
- 队徽和图标使用本地 PNG，保留可编辑原始 SVG/生成源，不依赖外网图标 CDN。
- 普通卡片使用细边框与 9–10px 圆角；不叠加大量阴影、渐变或多套无关视觉语言。
- uni-app 的 button 组件有平台默认样式。所有按钮必须使用 ui-button 基础类，功能类在其之后覆盖样式。

## 信息层级

1. 比赛双方和比分。
2. 比赛状态与时间。
3. 场地、轮次、辅助说明。

状态使用文字，不只使用颜色。未开始的比分使用 VS，不使用 0:0。待定球队显示签位来源，不生成虚构胜者。

## 交互

- 首页、赛程、对阵图、球队详情必须引用同一份比赛记录。
- 对阵图仅在局部区域横向滚动，禁止撑宽整页。
- 筛选必须真实影响列表，并有无结果与重置入口。
- 所有可见主按钮都需产生可见结果，不用无意义 toast 代替主要流程。
- 关注为本地演示功能，明确说明不上传服务器。
- 详情缺少 ID/资料时显示友好错误，不白屏。
- 搜索弹窗可关闭，H5 支持 Escape、Tab 焦点约束；按钮支持键盘激活。
- 不通过颜色区分真实/模拟；模拟日期、模拟赛况始终有文字说明。

## 验收尺寸

320、390、768、1440px。浏览器通过后仍需微信开发者工具与真机确认。特别检查胶囊避让、安全区、长队名、图片缺失、空列表和未定签位。
