## 本地启动与构建

```bash
npm ci
npm run dev:admin
# 浏览器打开 http://127.0.0.1:5174/
npm run build:admin
```

后台代码位于 `admin/`，构建输出为 `dist/admin/`。它与微信小程序独立构建，共用项目依赖和云开发环境。当前机器文件监听资源紧张，若启动报 `EMFILE`，使用 `CHOKIDAR_USEPOLLING=true npm run dev:admin`；小程序和 H5 构建同样可使用此环境变量。

在项目根目录的 `.env.admin.local` 配置云函数 HTTP 访问服务实际提供的地址：

```dotenv
VITE_ADMIN_API_URL=https://cloud1-d2goo1h1mee3b7a38-1525008540.ap-shanghai.app.tcloudbase.com/admin-auth
```

以上为当前开发环境已验证的真实地址，已写入本机 `.env.admin.local`（Git忽略）。另一台电脑需要自行创建该文件。地址缺失时页面显示未配置，不能登录；不会连接演示账号。该变量公开打包到网页，禁止放入密码、令牌或云密钥。改配置后重新启动或构建后台。

## 云端接入步骤

网页版控制台必须登录原小程序云环境所属的腾讯云账号。本次曾发现普通腾讯云登录进入另一个账号，环境列表为空，现已解决并完成原环境路由配置。对于微信开发者工具内开通的环境，按 [官方账号说明](https://docs.cloudbase.net/faq/account)，应在腾讯云登录页选择“小程序公众号”扫码登录，由小程序管理员扫码并选择本项目小程序。普通“微信扫码登录”与“小程序公众号”登录方式需要区分；先确认原环境可见，再配置网关。

1. 使用已确认的开发环境 `cloud1-d2goo1h1mee3b7a38`，部署 `cloudfunctions/adminAuth`，选择云端安装依赖。
2. 数据库 `adminAccounts` 设置为“仅管理员可读写”，自定义规则为 `{"read":false,"write":false}`。通过小程序客户端实际验证读取与写入均被拒绝，再写入账号。云函数以服务端身份读写该集合。
3. 通过下面的本机脚本生成首个账号，将私有账号数据导入为 `adminAccounts/primary`。导入前核对文档不存在；不覆盖已有账号。
4. 打开网页版云开发控制台 `https://console.cloud.tencent.com/tcb`，选择原环境，进入“HTTP 网关 → 路由管理 → 新建”。域名选择默认域名，触发路径 `/admin-auth`，关联资源选择“云函数 / adminAuth”，保存并使用页面实际提供的 HTTPS 地址。入口须允许网页请求到达函数，由函数验证密码及会话；云函数适配标准 `httpMethod/headers/body/isBase64Encoded` 事件。HTTP 服务可用性、套餐要求及实际事件格式须通过真实请求验证。
5. 函数默认允许 `http://127.0.0.1:5174` 和 `http://localhost:5174`。正式后台域名确定后，将其完整 origin（协议和域名，无路径、无末尾斜杠）加入云函数环境变量 `ADMIN_ALLOWED_ORIGINS`，多个用英文逗号分隔。生产网页需 HTTPS。
6. 将真实 HTTP URL 写入 `.env.admin.local`，测试正确/错误登录、刷新、失效会话、退出撤销、断网重试和跨域预检。密码派生加数据库事务可能超过默认超时，须检查真实耗时；必要时在控制台将云函数超时调到 15 秒再复验。

官方文档已确认：自2026年6月起，“HTTP访问服务”改名为“HTTP网关”；微信开发者工具内嵌控制台当前未直接显示该菜单。配置以 [官方HTTP访问云函数文档](https://docs.cloudbase.net/service/access-cloud-function) 和 [HTTP网关概述](https://docs.cloudbase.net/service/introduce) 为准。微信开发者工具的自动化接口目前不提供数据库权限规则修改和HTTP网关配置；这些控制台配置需要用户操作。开发环境部署与正式网页托管、小程序审核发布是不同步骤，本次未发布生产版本。

## 首个账号与密码维护

```bash
npm run admin:prepare
```

脚本只在本机生成用户名 `admin`、随机强密码及密码哈希记录，不自动写云端。凭据位于 `.tools/admin-setup/credentials.txt`，导入数据位于 `.tools/admin-setup/account.json`；目录权限 0700、文件权限 0600，均已被 Git 忽略。已生成时拒绝覆盖，请不要重复执行或把文件提交到仓库。

当前首期只有一个管理员，无公共注册、网页改密或重置密码接口。需要重置时由有云控制台权限的维护者生成新的盐、哈希和 `credentialVersion`，在受控更新中清空 `sessions`；不得直接向网页暴露云管理密钥。正式交付前安排账号保管和恢复流程。
